## Brief Overview

Amazon Web Services (AWS) is a major public cloud computing platform. It provides a wide range of cloud services that organizations can use to build, deploy, store, manage, and scale applications.

## Global Infrastructure

AWS uses a global infrastructure consisting of Regions and Availability Zones. Regions represent geographic areas, while Availability Zones provide isolated infrastructure within regions. This structure helps organizations design applications with availability and resilience.

## Cloud Management Console

The AWS Management Console is a web-based interface used to manage AWS resources. Through the console, users can create and configure computing resources, storage, databases, networks, security settings, and other cloud services.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud provides virtual computing capacity that can be scaled according to application requirements.

### 2. Amazon S3

Amazon Simple Storage Service provides object storage for storing and retrieving different types of data.

### 3. Amazon VPC

Amazon Virtual Private Cloud provides networking capabilities for creating isolated cloud networks.

### 4. AWS IAM

AWS Identity and Access Management allows administrators to manage users, roles, permissions, and access to AWS resources.

## Three Advantages

1. **Scalability** – Resources can be increased or decreased depending on demand.
2. **Global Infrastructure** – AWS provides cloud infrastructure in many geographic locations.
3. **Service Variety** – AWS provides many services for computing, storage, databases, networking, security, analytics, and other workloads.

## Typical Enterprise Use Cases

AWS can be used for:

- Web application hosting
- Mobile application backends
- Data storage
- Database systems
- Backup and disaster recovery
- E-commerce applications
- Artificial intelligence
- Enterprise applications
