## Brief Overview

Microsoft Azure is a public cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, analytics, artificial intelligence, security, and enterprise applications.

## Global Infrastructure

Azure provides cloud infrastructure through geographic regions and data centers around the world. Azure also supports Availability Zones in selected regions to help organizations improve application resiliency.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources. Users can manage virtual machines, storage, networks, databases, identities, and other cloud services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide scalable computing resources for Windows and Linux workloads.

### 2. Azure Blob Storage

Azure Blob Storage provides object storage for large amounts of unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network allows Azure resources to communicate through private and controlled network environments.

### 4. Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and resources.

## Three Advantages

1. **Microsoft Integration** – Azure works well with Microsoft's existing technologies.
2. **Enterprise Support** – Azure provides services suitable for enterprise environments.
3. **Global Infrastructure** – Azure provides cloud infrastructure across many regions.

## Typical Enterprise Use Cases

Azure can be used for:

- Windows Server workloads
- Enterprise applications
- Hybrid cloud environments
- Database hosting
- Web applications
- Virtual desktops
- Identity management
- Artificial intelligence
