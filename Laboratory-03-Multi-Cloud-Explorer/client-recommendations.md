## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended for the startup because it provides flexible cloud services that can support an application as it grows. The company can begin with the resources it needs and increase them when demand increases. AWS also provides services for computing, storage, databases, and application development. This allows the startup to build its application without having to purchase a large amount of physical infrastructure.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and identity management. The university can gradually migrate selected services while maintaining compatibility with its existing environment. Azure can also support hybrid cloud configurations.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is recommended for the AI research company because it provides services for artificial intelligence, machine learning, and high-performance workloads. Researchers can use scalable computing resources for experiments and application development. Google Cloud also provides managed Kubernetes services for containerized applications. These capabilities make it suitable for modern AI research environments.

### Recommended Services

- Compute Engine
- Google Kubernetes Engine
- Vertex AI

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it provides global infrastructure and scalable cloud services. The company can distribute its applications across multiple locations to improve availability. AWS also provides load balancing and scalable computing resources that can respond to changing traffic. These features are useful for an online shopping platform with customers around the world.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- Amazon RDS
